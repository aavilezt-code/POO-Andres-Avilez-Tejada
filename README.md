## Descripción del curso
Este repositorio contiene las actividades prácticas del curso de **Programación Orientada a Objetos 2026-2S**. Cada actividad aborda conceptos específicos de POO usando **Java** como lenguaje de programación, basándose en el libro **"Ejercicios de programación orientada a objetos con Java y UML"** de Leonardo Bermón Angarita.

## Actividades

### Actividad 1 (10%)
**Conceptos básicos de POO**

- Definición de clases, atributos y métodos
- Constructores y encapsulación
- Getters y setters

### Actividad 2 (20%)
**POO intermedia**

- Definición de atributos con tipos primitivos
- Métodos con y sin valores de retorno
- Métodos con parámetros
- Figuras geométricas y operaciones bancarias

### Actividad 3 (10%)
**Interfaces Gráficas y Modelado UML**

- Desarrollo de Interfaces Gráficas de Usuario (GUI)
- Ejercicio 8.2 y 8.3 (Notas de estudiantes y Figuras geométricas)
- Diseño de diagramas UML (Clases, Objetos y Casos de Uso)

### Actividad 4 (20%)
**Excepciones, Validación de Campos y Lectura de Archivos con Interfaz Gráfica**

- Manejo de excepciones (`try`, `catch`, `finally`), lanzamiento explícito (`throw`) y bloques `catch` múltiples
- Ejercicios 6.4, 6.5, 6.6, 6.7 y 6.8 con interfaz gráfica en Java Swing
- Validación de datos de entrada y lectura de archivos de texto mediante flujos (`java.io`)
